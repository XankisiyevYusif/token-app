What is an LLM?

LLM stands for Large Language Model — an AI system trained on large amounts of text using a Transformer architecture. It generates responses by predicting the next token one at a time, based on all previous tokens.

Two well-known examples:

  • GPT-5.4 (OpenAI) — flagship model for reasoning, coding, and multimodal tasks.
  • Claude Sonnet 4.6 (Anthropic) — strong at long documents with a 1M token context window.

What is a Token?

A token is the basic unit of text an LLM processes — a subword chunk roughly 3–4 characters long, or about ¾ of an English word.

Tokens matter because the context window (max text per request) and API pricing are both measured in tokens.

Example: "Hello, world!" → ~4 tokens: Hello, ,, world, !. A 1,000-word document is roughly 1,300–1,500 tokens.

English vs Azerbaijani: English is token-efficient — common words are often one token. Azerbaijani, being agglutinative, uses more tokens per word. A 10-token English sentence may need 15–20 tokens in Azerbaijani, increasing cost and context usage.
