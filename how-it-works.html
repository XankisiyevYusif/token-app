How an LLM Works

From the moment you press Enter to the first word of the response, here is what happens inside a large language model.

  1. 1

    User Input

    You type a prompt and submit it. This raw text is sent to the model's API as plain text waiting to be interpreted.

  2. 2

    Tokenisation

    The tokeniser breaks the text into tokens: small chunks of roughly 3 to 4 characters. For example, ["Hello", ",", " world", "!"]. Each token is mapped to a unique integer ID from the model's vocabulary.

  3. 3

    Embedding

    Each token ID is looked up in an embedding table and converted into a high-dimensional vector of floating-point numbers. These numbers encode the semantic meaning of the token in a form the neural network can process.

  4. 4

    Attention Layers

    The embeddings pass through dozens of Transformer blocks. Each block runs a self-attention mechanism that lets every token "look at" every other token in the context and decide how much to weight each one when building its own representation.

  5. 5

    Prediction

    After the final Transformer block, a linear layer projects the last hidden state into a probability distribution over the entire vocabulary — tens of thousands of tokens. The highest-probability (or sampled) token becomes the next output.

  6. 6

    Output Generation

    The predicted token is appended to the context and the whole process repeats — one token at a time — until the model generates a stop token or reaches the maximum output length. The token IDs are then decoded back into readable text and streamed to your screen.
